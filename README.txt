Сайт технического задания РКИ 2026–2027

Открытие
Распакуйте весь архив и откройте index.html в браузере. Сервер, установка библиотек и подключение к интернету для самого сайта не требуются. Внешние ссылки на шаблоны, GitHub и Telegram открываются при наличии интернета.

Страницы
index.html — обзор задания
general/index.html — общая информация
age-rating/index.html — ограничения возрастного рейтинга 12+
game-design/index.html — геймдизайн
art/index.html — арт
programming/index.html — программирование
product/index.html — продукт
submission/index.html — порядок сдачи

Возможности
Поиск по всему заданию, Ctrl+K, оглавления страниц, навигация с клавиатуры, адаптация к мобильному экрану, печать и копирование ссылок.
Кнопка с луной или солнцем вверху справа переключает светлую и тёмную тему. Выбор сохраняется; при первом открытии используется тема системы. При переходах между локальными HTML-страницами выбранная тема сохраняется даже при отключенном хранилище браузера.

Редактирование
Можно редактировать HTML напрямую. Для согласованного обновления страниц и поискового индекса измените source/pages.json и выполните из каталога сайта:
python source/build.py
Генератор использует только стандартную библиотеку Python 3.
Основные стили задаются в styles.css и extras.css, тёмная палитра — в theme.css. Поведение страницы — в app.js, выбор темы — в theme.js.

Содержание
Сборка требуется только в блоке «Продукт». На соответствующих страницах указаны шаблоны геймдизайна, программирования и презентации проекта, а также аккаунты доступа к репозиторию.
По всем вопросам участники могут обращаться к организаторам в соответствующих темах Telegram-группы: https://t.me/ontigamedev
